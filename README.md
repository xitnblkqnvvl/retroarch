## Overview

RetroArch is the definitive universal emulator frontend, running hundreds of emulator cores via the standardized libretro API across all major desktop and mobile platforms. It provides unified shader pipelines, netplay, achievements via RetroAchievements, rewind, run-ahead latency reduction, and a single configuration interface managing every emulated system.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RetroArch** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Hundreds of Cores** | Single frontend for over 100 emulator cores spanning all classic systems |
| **Shaders** | Comprehensive shader library for scanlines, CRT phosphor, and scaling |
| **Netplay** | Built-in peer-to-peer online play for any libretro core that supports it |
| **RetroAchievements** | Trophy-style achievement unlocks synced to the RetroAchievements database |
